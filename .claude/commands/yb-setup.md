CLAUDE.md 의 "🤖 윤비서 CLI(yb) 설치 도우미" 절차를 그대로 따라 yb 를 설치하고 연결해줘.

- 한 번에 한 단계씩 진행하고, 각 단계 결과를 확인한 뒤 다음으로 넘어간다.
- API 키는 채팅에 다시 출력하지 않는다. `yb login` 은 연결할 때 한 번만 실행한다.
- 끝나면 `yb whoami` 로 나온 이름과 `yb today` 결과를 쉬운 말로 알려 준다.
