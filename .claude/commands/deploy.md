CLAUDE.md 의 "🚀 배포 도우미 (Vercel)" 절차를 그대로 따라 배포를 진행해줘.

- `vercel login` 같은 브라우저 인증은 사용자가 새 터미널에서 직접 실행하도록 안내한다.
- 환경변수는 `.env.local` 에서 읽어 네가 직접 등록하되, 값을 채팅에 출력하지 않는다.
- 배포 후 프로덕션 URL 을 확인(HTTP 200)하고 사용자에게 알려준다.
- 기본 비밀번호(jadong!)를 아직 쓰고 있으면 배포 전에 변경을 권한다.

지금 1단계(vercel whoami 로그인 확인)부터 시작해줘.
