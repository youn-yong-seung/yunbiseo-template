# 윤비서 CLI 시작하기

AI 앱(Claude Code 앱, Codex 앱)에게 **말로 윤비서 일을 시키는 방법**입니다.
"오늘 일정 알려줘", "다음 주 화요일 2시에 미팅 잡아줘"라고 말하면 AI가 윤비서에 대신 들어가 조회하고 등록합니다.
AI와 윤비서를 이어 주는 연결선이 `yb`(윤비서 CLI)입니다. 처음 한 번만 연결해 두면 됩니다.

강사·수강생이 같이 보는 안내서입니다. 개발을 몰라도 따라 할 수 있게 썼습니다.

---

## 0. 준비물 세 가지

| 준비물 | 어디서 받나요 | 적어 두는 칸 |
|---|---|---|
| **윤비서 접속 주소** | 내가 설치했다면 내 주소(예: `https://우리회사.vercel.app`, 내 컴퓨터에서만 쓰면 `http://localhost:3000`). 강의용 테스트 환경이면 강사가 알려 줍니다. | `https://______________________` |
| **내 계정** (로그인 ID·비밀번호) | 관리자가 [직원관리]에서 만들어 줍니다. 처음 설치한 사람은 `npm run setup:admin` 이 보여 준 `admin` 계정입니다. | ID `________` |
| **AI 앱** | Claude Code 앱 또는 Codex 앱. 컴퓨터에 설치하고 로그인해 둡니다. | |

> 내 컴퓨터에 Node.js 가 없어도 괜찮습니다. 2단계에서 AI가 확인하고 설치를 도와줍니다.

---

## 1단계. 윤비서에서 "내 API 키" 만들기

API 키는 AI 앱이 **내 이름으로** 윤비서를 쓰게 해 주는 열쇠입니다. 비밀번호처럼 다룹니다.

1. 윤비서 주소로 들어가 내 계정으로 로그인합니다.
2. 화면 **왼쪽 사이드바 맨 아래의 '내 이름'** 을 누릅니다. → **마이페이지**가 열립니다.
3. 아래로 내려 **'내 API 키'** 칸을 찾습니다.
4. 키 이름에 알아보기 쉬운 이름(예: `내 노트북 Claude Code`)을 적고 **[새 API 키 만들기]** 를 누릅니다.
5. `ys_` 로 시작하는 긴 값이 나옵니다. **복사 버튼**으로 복사합니다.
   **이 값은 지금 한 번만 보입니다.** 놓쳤으면 그 키를 지우고 새로 만들면 됩니다.

> 관리자는 **왼쪽 아래 '관리자 메뉴' → 시스템 설정 → API Key 관리** 에서도 키를 만들 수 있고,
> 모든 직원의 키 목록을 보고 지울 수 있습니다(다른 사람 키의 값은 관리자도 볼 수 없습니다).

---

## 2단계. AI 앱에게 설치 부탁하기

AI 앱을 열고 아래처럼 말합니다. 주소와 키 자리에 1단계 값을 넣습니다.

> **윤비서 CLI 설치해줘. 주소는 `https://우리회사.vercel.app` 이고 API 키는 `ys_...` 야.**

AI가 알아서 하는 일:
1. 컴퓨터에 Node.js 가 있는지 확인하고, 없으면 설치를 안내합니다(설치 창의 '허용' 같은 버튼은 직접 눌러 주세요).
2. `yb` 를 설치합니다.
3. 주소와 키로 연결하고(`yb auth --key ... --url ...`), 연결이 맞는지 바로 확인합니다.
4. `yb whoami` 로 **"시험직원"처럼 내 이름이 나오면 성공**입니다.

### 키를 채팅에 붙여 넣기 싫다면 (브라우저로 연결)

> **윤비서 CLI 설치해줘. 주소는 `https://우리회사.vercel.app` 이야. 키는 브라우저로 연결할게.**

AI가 `yb login` 을 한 번 실행하면 브라우저에 윤비서 화면이 뜹니다. 로그인한 뒤
**[이 컴퓨터에서 yb CLI 인증]** 을 누르면 끝입니다. 키를 복사할 필요가 없습니다.
(이 연결은 처음 한 번만 합니다. 그 뒤로 AI는 `yb whoami` 로 내 이름만 확인합니다.)

## 3단계. 이렇게 말해 보세요

| 하고 싶은 일 | AI 앱에 할 말 | AI가 쓰는 명령(참고) |
|---|---|---|
| 오늘 일정·할 일 보기 | "오늘 일정 알려줘" | `yb today` |
| 이번 주 일정 | "이번 주 내 일정 보여줘" | `yb schedule list --from 오늘 --to 일 --assignee me` |
| 일정 추가 | "다음 주 화요일 오후 2시에 ○○상사 미팅 추가해줘" | `yb schedule create --title "○○상사 미팅" --date "다음주 화" --time 14:00 --category meeting` |
| 일정 옮기기 | "그 미팅 3시로 바꿔줘" | `yb schedule update <일정id> --time 15:00` |
| 할 일 맡기기 | "나한테 견적서 보내기 내일까지로 넣어줘" | `yb give 나 "견적서 보내기" --due 내일` |
| 매출 등록 | "○○상사 컨설팅 매출 110만원(부가세 포함) 등록해줘" | `yb revenue create --title "○○상사 컨설팅" --total 1100000` |
| 고객 전화번호 | "○○상사 전화번호 알려줘" | `yb customer get ○○상사` |
| 세금계산서 상태 | "○○상사 컨설팅 매출 세금계산서 발행됐어?" | `yb revenue list --q ○○상사` → `yb revenue tax-invoice status <매출id>` |
| 고객 등록 | "고객 ○○상사 등록해줘. 전화 02-123-4567" | `yb customer create --name ○○상사 --phone 02-123-4567` |

- 시간을 빼먹고 "미팅 잡아줘"라고 하면 AI가 몇 시인지 되묻습니다.
- **세금계산서 발행처럼 밖으로 나가는 일**은 AI가 미리보기를 보여 주고, 내가 "발행해"라고 한 뒤에만 합니다.
- 일정·할 일은 회사 직원 모두가 볼 수 있지만, **고치거나 지우는 것은 만든 사람·담당자·관리자만** 됩니다.
- 구글 캘린더를 연결해 둔 회사라면 일정이 캘린더에도 같이 들어갑니다. 연결이 없어도 윤비서에는 그대로 저장됩니다.

## 막힐 때

| 이런 말이 나오면 | 이렇게 하세요 |
|---|---|
| "이 키로 윤비서에 연결하지 못했습니다" | 주소 끝에 오타가 없는지, 키를 끝까지 복사했는지 확인합니다. 그래도 안 되면 마이페이지에서 키를 새로 만들어 다시 부탁합니다. |
| `yb whoami` 에 `invalid_api_key` | 키가 지워졌거나 내 계정이 비활성화된 것입니다. 마이페이지에서 새 키를 만들고, 그래도 안 되면 관리자에게 계정 상태를 물어봅니다. |
| `HTTP 401` | 위와 같습니다(키·계정 문제). |
| `HTTP 403` "만든 사람·담당자·관리자만" | 내 권한 밖의 일입니다. 그 일정·할 일을 만든 사람이나 관리자에게 부탁합니다. |
| "수강생판에서는 아직 지원하지 않는 명령" | 템플릿에 아직 없는 기능입니다. `yb help` 로 쓸 수 있는 명령을 봅니다. |
| `yb: command not found` / "인식되지 않습니다" | AI 앱에게 "yb 가 안 잡혀. 다시 설치해줘"라고 말합니다. 창을 새로 열면 해결되기도 합니다. |
| "요청 실패: fetch failed" | 윤비서 주소에 접속이 안 되는 상태입니다. 브라우저로 그 주소가 열리는지 먼저 봅니다(내 컴퓨터 주소 `localhost` 는 `npm run dev` 가 켜져 있어야 합니다). |
| 로그인 화면에서 "15분 동안 로그인할 수 없습니다" | 비밀번호를 5번 틀려 잠긴 것입니다. 15분 뒤 다시 하거나 관리자에게 비밀번호 초기화를 부탁합니다. |

### 안전하게 쓰는 법
- API 키는 비밀번호와 같습니다. 단톡방·메일에 올리지 않습니다.
- 채팅에 붙여 넣은 키는 그 AI 앱 대화 기록에 남습니다. 꺼림칙하면 브라우저 연결(2단계 아래)을 쓰거나, 다 쓴 뒤 마이페이지에서 키를 지우고 새로 만듭니다.
- 노트북을 잃어버리거나 바꾸면 마이페이지 → 내 API 키에서 그 키를 지웁니다. 즉시 막힙니다.
- 키는 만든 사람 이름으로 동작합니다. 퇴사자 계정을 비활성화하면 그 사람 키도 같이 막힙니다.

## 강사용 메모: 테스트 환경 준비

- 테스트 회사 데이터는 저장소의 `scripts/seed-sample-data.mjs` 로 넣을 수 있습니다(가상의 고객·프로젝트·매출·일정).
  실행 전 반드시 **테스트용 Supabase** 의 `.env.local` 인지 확인합니다: `node scripts/seed-sample-data.mjs --yes`
- 수강생 계정은 관리자 계정으로 [직원관리] → 직원 등록(로그인 ID 입력) 하면 임시 비밀번호가 한 번 나옵니다. 그 ID·비밀번호를 수강생에게 따로 전달합니다.
- 수강생은 각자 자기 계정으로 로그인해 1단계부터 하면 됩니다. 한 사람의 키로 여러 명이 쓰지 않습니다(누가 한 일인지 섞입니다).
