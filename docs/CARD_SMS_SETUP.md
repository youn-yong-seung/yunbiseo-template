# 법인카드 문자 연동 설정 (Claude Code 와 같이 하기)

카드로 결제하면 오는 승인 문자를 폰이 윤비서로 보내게 해서, **법인카드** 메뉴에 결제가 자동으로 한 줄씩 쌓이게 합니다.

> **가장 쉬운 방법:** Claude Code 에게 **"카드 문자 연동 도와줘"** 라고 말하세요.
> 서버 쪽 확인과 시험은 Claude Code 가 하고, 폰 화면에서 누르는 것만 내가 합니다(폰은 Claude Code 가 만질 수 없습니다).

## 누가 무엇을 하나

| 순서 | 할 일 | 누가 | 걸리는 시간 |
|---|---|---|---|
| 1 | 윤비서가 인터넷에 배포됐는지, 법인카드 테이블이 있는지 확인 | Claude Code | 1분 |
| 2 | 법인카드 메뉴 → 카드 관리에서 카드 끝 4자리 등록 | 나 (웹) | 1분 |
| 3 | 시스템 설정 → API 키에서 **문자 연동 전용 키** 만들기 | 나 (웹) | 1분 |
| 4 | 시험 문자를 서버로 보내 한 줄이 생기는지 확인 | Claude Code | 1분 |
| 5 | 내 주소·키를 채운 폰 설정표 만들어 주기 | Claude Code | - |
| 6 | 폰에서 단축어(아이폰) 또는 MacroDroid(안드로이드) 설정 | 나 (폰) | 5~10분 |
| 7 | 소액 결제 → 들어왔는지 확인 | 나 결제, Claude Code 확인 | 1분 |

## 폰 설정 (6단계)

보낼 곳은 하나입니다. 5단계에서 Claude Code 가 아래 표를 내 값으로 채워 줍니다.

| 항목 | 값 |
|---|---|
| 주소 | `https://내-윤비서-주소/api/card-transactions/webhook` |
| 방법 | `POST` |
| 헤더 | `x-api-key` = 문자 연동 전용 키 |
| 본문 | 문자 원문 그대로(텍스트), 또는 JSON `{"text": "문자 원문"}` |

### 아이폰: 단축어 자동화 (iOS 17 이상)
1. **단축어** 앱 → 아래 **자동화** 탭 → 오른쪽 위 `+` → **메시지**.
2. **메시지에 포함**에 `승인` 입력 (카드사 문자 번호를 알면 **보낸 사람**에 넣어도 됩니다).
3. **즉시 실행** 선택 (실행 전 확인 끄기) → **다음** → **새로운 빈 자동화**.
4. **동작 추가** → `URL` 검색 → **URL의 콘텐츠 가져오기**.
   - URL 칸: 위 주소
   - 펼치기(`>`) → **방법: POST**
   - **헤더 추가**: 키 `x-api-key`, 값 문자 연동 전용 키
   - **본문 요청: JSON** → 필드 추가 → **텍스트**, 키 `text`, 값은 변수 **단축어 입력** (메시지 내용)
5. **완료**.

### 안드로이드: MacroDroid (무료)
1. Play 스토어에서 **MacroDroid** 설치 → **매크로 추가**.
2. **트리거** `+` → **알림** → **알림 수신** → 앱: 문자 앱(메시지) → **텍스트 포함** `승인`.
   알림 접근 권한을 묻으면 허용합니다. (카드사 문자는 'SMS 수신' 트리거로 안 잡히는 경우가 있어 **알림**을 씁니다.)
3. **동작** `+` → **웹 연동(Web Interactions)** → **HTTP 요청**.
   - 방법 **POST**, URL 위 주소
   - **헤더**: `x-api-key` = 문자 연동 전용 키
   - **본문(Body)**: 형식 `text/plain`, 내용은 `...` 버튼(매직 텍스트) → **알림 텍스트**
4. 매크로 이름(예: 카드문자) 저장.
5. 휴대폰 **설정 → 애플리케이션 → MacroDroid → 배터리 → 제한 없음**. 꺼져 있으면 문자가 빠집니다.

### 키를 폰에 옮기는 법
키는 길어서 손으로 치기 어렵습니다. 아래 중 편한 것으로 옮기고, 붙여넣은 뒤에는 지웁니다.
- 아이폰과 맥: 맥에서 키를 복사하면 아이폰에서 바로 붙여넣기(같은 Apple ID, 유니버설 클립보드).
- Claude Code 에게 **"키를 QR 로 보여줘"** → 폰 카메라로 비추고 텍스트 복사.
- 카톡 '나와의 채팅'처럼 남는 곳에는 붙여넣지 않는 게 좋습니다.

## 안 들어올 때

| 증상 | 원인과 해결 |
|---|---|
| 아무것도 안 들어옴 | 폰 자동화가 안 돌았음. 아이폰은 **즉시 실행**, 안드로이드는 **알림 접근 권한**과 **배터리 제한 없음** 확인 |
| 단축어 실행 기록에 401 | 키가 틀림. 헤더 이름이 정확히 `x-api-key` 인지, 키 앞뒤 공백이 없는지 확인 |
| 400 "문자 내용이 비어 있습니다" | 본문이 빠짐. 아이폰은 값이 **단축어 입력**인지, MacroDroid 는 **알림 텍스트**인지 확인 |
| 한 줄은 생겼는데 가맹점이 비어 있음 | 카드사 문자 모양이 달라 못 읽음. 화면에서 고치고, Claude Code 에게 문자 원문을 보여 주며 "해석기 고쳐줘" |
| 카드가 '(미등록)'으로 나옴 | 2단계에서 끝 4자리를 등록 안 함. 등록하면 지난 내역도 자동으로 이어집니다 |
| 폰 주소가 localhost | 폰은 내 컴퓨터에 닿지 않습니다. Vercel 배포 주소(`https://...vercel.app`)를 씁니다 |

## (Claude Code 용) 진행 절차

트리거: "카드 문자 연동 도와줘", "법인카드 연동", "폰 연결했어 설정해줘", "카드 문자 받게 해줘".
위 표의 순서대로 **한 번에 한 단계씩** 진행한다. 폰 조작은 대신할 수 없으니 정확한 화면 이름으로 안내만 한다.

1. **배포 주소 확인.** `vercel ls` 또는 `.vercel/project.json`, 사용자에게 들은 주소로 `https://…` 주소를 정한다.
   localhost 뿐이면 먼저 CLAUDE.md '배포 도우미'로 배포한다. `curl -s -o /dev/null -w "%{http_code}" <주소>/login` 이 200 인지 본다.
2. **테이블 확인.** `supabase db push` 를 한 번 실행해 밀린 마이그레이션이 없게 한다(새 게 없으면 그대로 끝남).
   배포본이 최신 코드인지도 본다: `curl -s -X POST <주소>/api/card-transactions/webhook` 이 401 이면 있음, 404 면 재배포(`vercel --prod`).
3. **카드 등록 안내.** 웹 **법인카드 → 카드 관리**에서 끝 4자리를 등록하게 한다. 등록 뒤 `yb card list --limit 1` 이 되는지 본다.
4. **전용 키 안내.** 웹 **시스템 설정 → API 키 → 새 키**, 이름 `카드 문자 (폰)`. 사용자가 키를 채팅에 붙여넣으면 받아서 쓰되
   **채팅에 다시 출력하지 않고 파일에도 저장하지 않는다.** (yb 로그인 키를 폰에 쓰지 않는다. 폰을 잃어버리면 그 키만 지우게 하려는 것.)
5. **서버 시험.** 등록한 끝 4자리로 시험 문자를 보낸다(카드사와 상관없이 해석되는 농협 형식을 쓴다).
   ```bash
   curl -s -X POST <주소>/api/card-transactions/webhook -H "x-api-key: <전용키>" -H "content-type: text/plain" \
     --data-binary $'[Web발신]\nNH기업<끝4자리>승인\n홍길동\n1,000원 일시불\n<MM/DD HH:mm>\n연동시험'
   ```
   `success: true` 와 한 줄이 오면 `yb card list --q 연동시험` 으로 보고, 확인 후 `yb card delete <id>` 로 지운다.
6. **폰 설정표 출력.** 사용자 폰 종류(아이폰/안드로이드)를 묻고, 위 '폰 설정' 해당 절을 **주소를 실제 값으로 채워** 보여 준다.
   키는 "4단계에서 만든 키"라고만 적는다. 원하면 `npx -y qrcode-terminal "<전용키>"` 로 QR 을 띄워 준다.
7. **실결제 확인.** 사용자가 소액 결제했다고 하면 `yb card list --limit 3` 으로 들어왔는지 본다.
   안 들어왔으면 위 '안 들어올 때' 표로 원인을 하나씩 좁힌다. 가맹점이 비면 문자 원문(`yb card get <id>` 의 raw_text)을 보고
   `src/lib/card-sms-parser.ts` 를 고칠지 사용자에게 묻는다.
